# Change: ساخت ماتریسی محصولات ورق و رول

## Why
مالک پس از توضیح ماتریس ورق کاویان، ساخت آن را درخواست کرد. ثبت تکی ترکیب‌های ضخامت/عرض/طول وقت‌گیر است؛ طول ثابت و بیش از یک حد باید محصول و قیمت مستقل داشته باشند.

## What Changes
- جدول ترکیب‌ها در بخش محصولات با مشخصات مشترک، انتخاب ردیف‌ها، قیمت و وضعیت موجودی جدا و چسباندن قیمت از اکسل.
- پیش‌نمایش بدون نوشتن و ثبت اتمیک حداکثر ۱۰۰ ترکیب در API مدیریتی.
- این مسیر فقط محصول جدید می‌سازد؛ موارد موجود را نشان می‌دهد و رد می‌کند، بدون تغییر قیمت/موجودی قبلی.
- استفاده از مدل‌ها و نقش‌های موجود؛ بدون migration یا دفتر موجودی تعدادی جدید.

## Impact
Backend products service/actions/tests; frontend matrix component/helpers and product-panel entry. Existing single-product and Excel upsert remain available.

## Authorization
درخواست واقعی مالک «اینو برای من بساز» به طرح توضیح‌داده‌شده با مشخصات مشترک، جدول تفاوت‌ها، پیش‌نمایش و ثبت گروهی اشاره دارد. تأیید قبلی مجوز تغییر دامنه‌های دیگر یا انتشار سرور نیست.
