# PRD اجرایی: هسته مدیریت محتوا و SEO

## خلاصه

این فاز، بخش عملیاتی اولیه سیستم تولید و مدیریت محتوای کاوکس را پیاده‌سازی می‌کند. هدف این است که مدیر محتوا بدون ورود به Django Admin بتواند مقاله بسازد، ذخیره کند، پیش‌نمایش ببیند، متادیتای SEO را تنظیم کند، امتیاز SEO دریافت کند و مقاله را فوری یا زمان‌بندی‌شده منتشر کند.

## قابلیت‌های این فاز

- CRUD مقاله با وضعیت‌های پیش‌نویس، بررسی، تایید، زمان‌بندی، انتشار، به‌روزرسانی و بایگانی.
- ذخیره خودکار پیش‌نویس در پنل محتوا هر ۳۰ ثانیه.
- تاریخچه نسخه‌ها و بازیابی نسخه قبل.
- متادیتای SEO شامل title، description، keyword، canonical، robots، Open Graph و schema type.
- امتیاز SEO و checklist برای عنوان، توضیحات، URL، H1، alt تصاویر، طول متن، لینک داخلی، تراکم کلیدواژه و schema.
- آپلود، پیش‌نمایش، جایگزینی و حذف تصویر اصلی مطلب همراه با متن جایگزین.
- آپلود تصویر داخل متن همراه با alt و درج در محل بلوک انتخاب‌شده یا انتهای مقاله.
- پذیرش فقط تصاویر PNG، JPEG و WebP تا سقف ۵ مگابایت برای رسانه‌های مقاله.
- نگهداری رسانه‌های runtime خارج از آرشیو کد و آماده‌سازی مالکیت و دسترسی نوشتن مسیر رسانه برای کاربر سرویس بک‌اند هنگام استقرار.
- خروجی JSON-LD مقاله، sitemap و robots.
- ISR برای صفحات عمومی بلاگ.
- ویرایش بلوکی متن اصلی با Editor.js و تولید HTML امن برای نمایش عمومی.
- جستجو و انتخاب دسته‌بندی، همراه با ساخت دسته جدید در مدال و انتخاب خودکار آن.
- پیشنهاد خلاصه، کلیدواژه اصلی و کلیدواژه‌های فرعی با OpenAI Responses API؛ اعمال پیشنهاد فقط با تایید نویسنده.

## خارج از محدوده این فاز

- تولید خودکار متن اصلی با AI.
- ابزارهای پیشرفته خارج از بلوک‌های پایه Editor.js.
- تبدیل WebP/AVIF و srcset در Celery.
- Redis، S3، CDN، Google Indexing API و Search Engine.
- i18n محتوایی، داشبورد Analytics، Broken Link Scanner و Internal Link NLP.

## معیار پذیرش

- ادمین بتواند از `/admin/content` مقاله جدید بسازد و draft ذخیره کند.
- draft در API عمومی وبلاگ دیده نشود.
- انتشار فوری یا زمان‌بندی‌شده، مقاله را در زمان صحیح عمومی کند.
- ویرایش مقاله revision بسازد و restore نسخه قبلی کار کند.
- مقدار SEO score و checklist در پنل نمایش داده شود.
- صفحه عمومی مقاله JSON-LD و metadata مناسب داشته باشد.
- `/sitemap.xml` فقط مطالب indexable منتشرشده را لیست کند و `/robots.txt` پاسخ متنی معتبر بدهد.
- اگر دسته مورد نظر موجود نبود، نویسنده بتواند از همان فرم دسته بسازد و دسته جدید خودکار انتخاب شود.
- متن اصلی در Editor.js نوشته شود و پس از ذخیره، HTML پاک‌سازی‌شده برای صفحه عمومی تولید شود.
- نویسنده بتواند پیشنهاد AI برای خلاصه و کلیدواژه‌ها بگیرد و پیش از اعمال آن‌ها را بررسی کند.
- نویسنده بتواند تصویر اصلی را در همان فرم مطلب بارگذاری، پیش‌نمایش، جایگزین یا حذف کند و نتیجه در صفحه عمومی دیده شود.
- نویسنده بتواند تصویر داخل متن را از ابزار تصویر ادیتور یا آپلود سریع، دقیقاً بعد از بخش فعال یا در انتهای متن درج کند.
- ترتیب بلوک‌های تصویر در پیش‌نمایش و HTML عمومی حفظ شود و فایل ناامن یا بزرگ‌تر از ۵ مگابایت رد شود.
- خطای دسترسی storage به‌صورت پاسخ JSON قابل‌فهم برگردد، تغییر مطلب rollback شود و اسکریپت استقرار پیش از restart نوشتنی‌بودن مسیر تصاویر را کنترل کند.
