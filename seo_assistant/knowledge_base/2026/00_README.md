# SEO Knowledge Base — 2026 Update Layer

> لایه‌ی به‌روزرسانیِ ۲۰۲۵–۲۰۲۶ روی پایگاه دانشِ پایه (`../knowledge-base/`).
> The fresh layer that updates the UC Davis course (2024-5) with the AI-search era.

## چرا این پوشه جداست؟ (Why separate)
پایگاهِ پایه از دوره‌ی ۲۰۲۴-۵ استخراج شده و اصولش هنوز معتبر است، اما «صحنه‌ی جستجو» از ۲۰۲۴ به این‌سو دگرگون شده: ظهور **AI Overviews** و **AI Mode** گوگل، موتورهای پاسخ مثل **ChatGPT Search / Perplexity / Gemini**، و انتقال از «رتبه‌بندی لینک‌آبی» به «**ذکر شدن (citation) در پاسخ‌های هوش مصنوعی**». این لایه را همیشه روی پایه سوار کنید.

> تاریخ واکشی: ژوئن ۲۰۲۶ (June 2026). منابع در `09_sources.md`.
