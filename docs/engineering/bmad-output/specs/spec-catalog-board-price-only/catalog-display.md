# قرارداد نمایش و مدیریت قیمت

مرکز طراحی «تابلوی مقایسهٔ فولاد» است، نه کارت‌های تبلیغاتی. رنگ‌ها: سرگروه
#123b54، زمینه #f3f6fa، سفید #ffffff، متن #0f172a، تعامل #2563eb، خرید #ea580c.
فونت IRANYekan موجود۴۰۰/۷۰۰؛ عددها tabular و واحدها واضح، نه تکرار نام کامل در
هر سلول. چیدمان RTL، نام راست‌چین، ستون عددی هم‌تراز و تاریخ مشخص.

```text
دسکتاپ: [کارخانه · خانواده · گرید/شکل] [تعداد]
        [سایز/ابعاد] [مشخصات ویژه] [وزن ثبت‌شده] [تحویل] [قیمت/واحد] [تأیید] [اقدام]
موبایل: [نام کوتاه/سایز]                  [گرید]
        [ابعاد و محل تحویل] [قیمت/واحد و تاریخ]
        [جزئیات]                       [خرید/استعلام]
```

گروه با کلید خانواده+factory(code)+شکل+گرید، نه label تنها؛ نامعلوم گروه مشخص.
میلگرد قطر/طول/گرید، ورق ضخامت/عرض/طول، رول ضخامت/عرض، نبشی دو بال/ضخامت/طول،
ناودانی سایز اسمی داینامیک/طول و فقط ارتفاع واقعاً ثبت‌شده، لوله قطر/ضخامت/طول،
پروفیل عرض/ارتفاع/ضخامت/طول، شمش و تیرآهن ابعاد ذخیره‌شده. خانوادهٔ سفارشی fallback
مشخصات ذخیره‌شده دارد. وزن و تاریخ نامعلوم «—»؛ هیچ محاسبهٔ حدسی. تاریخ از
price_verified_at، نه زمان بازشدن صفحه. قرارداد VAT قبلی حفظ و واحد قیمت نشان
داده شود. نشان مقایسهٔ میانگین مخلوطِ مبناها حذف؛ ادعای «بازار» از میانگین کاتالوگ
ساخته نشود. رفتار ناموجود بر خرید مقدم است. سه CTA تکراری به دو اقدام واضح کاهش یابد.

loading skeleton، empty با پاک‌کردن فیلتر، خطای قابل تلاش مجدد، focus آشکار، header
جدول semantic، لینک‌های قابل فهم، موبایل بدون سرریز کلی؛ در صورت نیاز اسکرول فقط
در محدودهٔ جدول. تصاویر مرجع فقط مرجع تراکم/گروه‌بندی‌اند، نه کپی هویت رقیب.

مدیریت: یک ردیف برای هر PricingTier با کالا، فروشنده، نام شرط، واحد، مبلغ و زمان؛
کلید draft برابر tier_id. مبلغ خالی/منفی/NaN/اعشار بیش‌از۲/دقت نامجاز رد؛ فیلد
اضافی رد، شناسهٔ تکراری یا ناموجود و expected_price ناسازگار = خطای batch بدون
ذخیره. کالای بی‌قیمت از پنل قیمت گروهی ساخته نمی‌شود؛ از مدیریت محصول ثبت شود.
فقط مبلغ و timestamp تغییر می‌کند؛ ممیزی و history خودکار است، نه بازنویسی هویت.
