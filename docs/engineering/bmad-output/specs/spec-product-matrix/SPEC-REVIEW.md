# بازبینی تطابق قرارداد

نتیجه: PASS پس از بررسی مستقل از نوشتن کد؛ بررسی کیفیت مستقل در `QUALITY-REVIEW.md` ثبت شده است.

| قابلیت | شواهد |
|---|---|
| CAP-1 | generator ورق/رول، dedup و حد قبل از Cartesian expansion؛ جدول قابل انتخاب؛ browser داده فقط انتخاب‌ها را می‌فرستد. |
| CAP-2 | قیمت/وضعیت مستقل، تومان با مبنای kg/ton/sheet، paste و اعمال گروهی؛ تست خراب‌بودن هزارگان ابتدا شکست خورد و سپس پاس شد؛ paste نامعتبر جدول را تغییر نمی‌دهد. |
| CAP-3 | preview روی Product/Spec ذخیره‌نشده؛ counts همه مدل‌های درگیر ثابت. commit اعتبارسنجی کامل و تراکنش محصول/offer/tier/audit دارد؛ خطای ردیف آخر هیچ بخشی ذخیره نمی‌کند؛ مجوز products صریح است. |
| CAP-4 | تست واقعی API دو طول و قیمت مستقل، حفظ public length_type، رد تکرار مشخصات، skip موارد قدیمی حتی با نام جدید و غیرفعال؛ قیمت و موجودی قبلی تغییر نمی‌کند. |

محدودیت address=255 و province/city=100 در سرور و UI هماهنگ شد. عدد نامتناهی/منفی/اعشار بیش از دو رقم، ناموجودبودن فروشنده و فیلدهای ناشناخته رد می‌شوند. تأیید به payload دقیق وابسته است و ویرایش آن را پاک می‌کند. بعد از خطای شبکه، پیش‌نمایش دوباره لازم است.

۱۲۷ تست بک‌اند، ۵۵ تست Node، browser واقعی با mock، regression منوی قبلی و build موفق‌اند. پوشش چندنخی PostgreSQL و اجرای زنده سرویس‌ها ادعا نشده است. دامنهٔ موجودی تعدادی، همه خانواده‌های آهن‌آلات یا deployment توسعه نیافت.
