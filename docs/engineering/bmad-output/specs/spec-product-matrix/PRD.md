# نیاز و قواعد

کاربر اصلی مدیر کالا است. هدف: ثبت چند ورق/رول در یک جدول بدون اشتباه در طول و قیمت. معیار: مثال ورق کاویان ۳۰ میل با طول ۶ متر و بیش از ۷ متر، دو محصول مستقل بماند؛ واردکردن دوباره قیمت قبلی را تغییر ندهد. مسیر پذیرفته‌شده: مشخصات مشترک ← محورهای ابعاد ← جدول انتخاب/قیمت/وضعیت ← پیش‌نمایش ← ثبت.

دامنه نخست ورق و رول است. موجودی همان وضعیت موجود/ناموجود/استعلام فعلی است. قیمت خالی یعنی استعلام، نه صفر یا حذف قیمت محصول قبلی. مقدار ابعاد میلی‌متر است؛ ورودی عدد فارسی پذیرفته می‌شود. فقط ردیف‌های انتخاب‌شده حداکثر ۱۰۰ عدد پردازش می‌شوند. موارد موجود حتی غیرفعال بازنویسی نمی‌شوند. خطای هر ردیف قابل اصلاح است؛ ثبت ناقص نداریم. پیش‌نمایش پس از هر تغییر از اعتبار می‌افتد.
